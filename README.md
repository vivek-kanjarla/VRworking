# VRworking — FR5 VR Teleoperation + ACT Imitation Learning

Collect demos by VR-teleoperating a Fairino FR5, train an ACT policy, deploy it.

- **`quest3-fairino-teleop/`** — Quest 3 → FR5 teleop + dual-camera episode recorder.
- **`fr5-act-policies/`** — ACT training & hardware-safe deployment (lerobot 0.5.1).
- **`ACT_PROGRESS.md`** — full working log (teleop, recording, training, deploy, diagnosis).

Code only; recorded data / datasets / `*.pt` checkpoints / venv are gitignored.
